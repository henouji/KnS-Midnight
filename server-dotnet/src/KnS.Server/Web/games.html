Installation guide

The original game's servers are gone, so this is a patched copy that talks to a private revival server. It is unofficial, for testing only, and may have bugs. Please don't share the APK.

Step 0 of 4

Download the APK

Use the download button above. You need about 1 GB free storage. If you have an older copy of the game from me installed, uninstall it first: your progress is saved on the server, not on the device.

Install it

  • Android 13 or older: open the file and allow "install unknown apps" when asked.
  • Android 14 or newer: Android refuses apps this old, so the install has to bypass the low target SDK block. Pick one option.
    • Option A, from a PC with adb:
      1. On the device: Settings, About, tap Build number 7 times, then Settings, Developer options, turn on USB debugging and connect the USB cable.
      2. On the PC, with Android platform-tools installed: 
        adb install -r --bypass-low-target-sdk-block kns.apk
        (replace kns.apk with the file name).
    • Option B, on the device itself (no PC):
      1. Install Shizuku from the Play Store and start it, following the steps inside the app (it uses Wireless debugging).
      2. Download InstallWithOptions from its GitHub releases and install it.
      3. Open InstallWithOptions, allow it to use Shizuku, choose the downloaded APK, turn on the option that bypasses the low target SDK block, and install.

First launch

A permissions screen appears. Tap Continue, then open the game again. Play Protect may warn about an unknown app; choose to install anyway.

Get access

The server only lets in people I have approved.

  • Open the game and tap Guest Play. You will get an error popup. That is expected.
  • Sign up with the email you want me to use and the time you tried (that is how I find your device), or message me both. I approve your device on the server.
  • Tap Guest Play again. You should be in.

Troubleshooting & FAQ

Install fails with "not compatible" or "app not installed"
Your device may be 64-bit only, or you skipped the low target SDK bypass (adb or InstallWithOptions) on Android 14 or newer. Tell me the exact message.
I get an error popup when I tap Guest Play
That is expected before approval. Sign up with your email and the time you tried. After I approve you, close the game fully, open it again and tap Guest Play.
Play Protect warns about an unknown app
The app is not from the Play Store, so Android warns. Choose to install anyway.
I was approved but still see the error popup
Close the game fully (swipe it away from recent apps) and open it again.
The game crashes or freezes
Tell me what you did just before, and your device model.
Will I keep my progress?
Progress is saved on the test server, not on your device, so reinstalling is fine. It belongs to this test server and may be wiped.
